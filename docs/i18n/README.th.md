## Briefing คืออะไร?

Briefing เป็นแอปจดโน้ตบนเดสก์ท็อป สำหรับทีมที่ต้องการ **ฐานความรู้ร่วมกันเพียงแห่งเดียว โดยไม่มีบริการคลาวด์อยู่ตรงกลาง**

- 📝 **เขียน** ลงในไฟล์ Markdown ธรรมดาที่อยู่ในโฟลเดอร์ปกติบนคอมพิวเตอร์ของคุณ ("vault" ของคุณ)
- 🔄 **แชร์** โฟลเดอร์กับทีม: คอมพิวเตอร์ทุกเครื่องเก็บสำเนาที่เหมือนกันทุกประการ และการเปลี่ยนแปลงจะส่ง **ตรงระหว่างคอมพิวเตอร์** แบบเข้ารหัสต้นทางถึงปลายทาง ภายในไม่กี่วินาที
- 🧠 **ถาม** ได้ทุกเรื่อง: ทุกโน้ตถูกทำดัชนีด้วยโมเดล AI ที่ทำงาน **บนเครื่องของคุณเอง** และ **Claude** (หรือไคลเอนต์ MCP ใดก็ได้) สามารถค้นหา อ่าน และเขียนโน้ตของคุณผ่านเซิร์ฟเวอร์ MCP ที่มีมาในตัว

ผลลัพธ์คือ คุณกับเพื่อนร่วมทีมสามารถทำงานพร้อมกันได้ โดยแต่ละคนใช้ Claude ของตัวเอง บนความรู้ชุดเดียวกันของบริษัท และเห็นเวอร์ชันล่าสุดเสมอ

> ขณะนี้อินเทอร์เฟซเป็น **ภาษาโปรตุเกส (บราซิล)** ยินดีรับการช่วยแปล — ดู [การมีส่วนร่วม](../../CONTRIBUTING.md)

## ทำงานอย่างไร

<div align="center"><img src="../images/architecture.svg" alt="สถาปัตยกรรม: คอมพิวเตอร์สองเครื่องซิงก์กันโดยตรง แต่ละเครื่องมีดัชนี AI บนเครื่องที่ Claude อ่านผ่าน MCP" width="860"></div>

1. **คุณสร้างทีม** และเลือกโฟลเดอร์ Briefing จะสร้างโค้ดเชิญ เช่น `BRF-7Q2M-…`
2. **เพื่อนร่วมทีมวางโค้ด** คอมพิวเตอร์จะหากันเจอผ่าน DHT สาธารณะของ [Hyperswarm](https://github.com/holepunchto/hyperswarm) — ซึ่งใช้ *เพื่อค้นหากันเท่านั้น* — แล้วเปิดการเชื่อมต่อโดยตรงที่เข้ารหัสด้วย Noise ทั้งสองฝ่ายต้องพิสูจน์ว่ารู้โค้ดก่อนจะมีการแลกเปลี่ยนไฟล์ใด ๆ
3. **ทุกการเปลี่ยนแปลงถูกส่งทันที** ไม่ว่าคุณ เพื่อนร่วมทีม หรือ Claude ตัวใดจะเป็นผู้เขียน การแก้ไขพร้อมกันจะถูกรวมทีละบรรทัด (แบบเดียวกับ Git) หากสองคนแก้บรรทัดเดียวกัน อีกเวอร์ชันจะถูกเก็บเป็น *สำเนาขัดแย้ง* ที่เหมือนกันทุกเครื่อง — ไม่มีอะไรสูญหาย
4. **คอมพิวเตอร์แต่ละเครื่องทำดัชนีโน้ตบนเครื่องเอง** (embedding หลายภาษา + การค้นหาด้วยคีย์เวิร์ด) Claude สอบถามดัชนีผ่าน MCP และได้ข้อความที่เกี่ยวข้องที่สุดภายในไม่กี่มิลลิวินาที

<summary><b>รายการฟีเจอร์ทั้งหมด</b></summary>

- แท็บ (กลับมาเหมือนเดิมเมื่อเปิดใหม่) สลับเร็ว พาเลตคำสั่ง ค้นหาข้อความทั้งหมดและค้นด้วย `#แท็ก`
- พรีวิวสด: ไวยากรณ์ Markdown จะซ่อนเมื่ออยู่นอกบรรทัดที่กำลังแก้ ตาราง กล่องเน้น รูปภาพ และช่องทำเครื่องหมายแสดงผลทันที
- พรีวิวเมื่อเลื่อนเมาส์ไปบนลิงก์ การกล่าวถึงที่ยังไม่ได้ลิงก์สามารถลิงก์ได้ในคลิกเดียว
- การเปลี่ยนชื่อหรือย้ายโน้ตจะอัปเดตทุกลิงก์ที่ชี้ไปยังโน้ตนั้น
- เทมเพลตพร้อมตัวแปร (`{{title}}`, `{{date:DD/MM/YYYY}}`, `{{time}}`) และเทมเพลต **บรีฟโปรเจกต์** ที่พร้อมใช้
- ประวัติเวอร์ชันของแต่ละโน้ตพร้อมกู้คืน สิ่งที่ลบจะเข้าถังขยะของระบบ
- ส่งออกโน้ตเป็น PDF
- ธีมสว่าง / มืด / ตามระบบ สีเน้น ขนาดตัวอักษร ความกว้างบรรทัด แผงที่ปรับขนาดได้ และโหมดโฟกัส
- ใช้ได้กับโฟลเดอร์ Markdown ที่มีอยู่แล้ว (รวมถึง vault ของ Obsidian)

## การติดตั้ง

ดาวน์โหลดเวอร์ชันล่าสุดสำหรับระบบของคุณจาก **[Releases](https://github.com/renankelm10/briefingMCP/releases)**

| ระบบ | ไฟล์ | หมายเหตุ |
|---|---|---|
| Windows 10/11 | `Briefing-Setup-x.y.z.exe` | ยังไม่ได้ลงนามโค้ด: ในคำเตือนของ SmartScreen ให้คลิก **ข้อมูลเพิ่มเติม → เรียกใช้ต่อไป** |
| macOS 12+ (Apple Silicon) | `Briefing-x.y.z-arm64.dmg` | ยังไม่ผ่านการรับรอง (notarize): คลิกขวาที่แอป → **เปิด** หรือรัน `xattr -dr com.apple.quarantine /Applications/Briefing.app` สำหรับ Mac ชิป Intel ให้ build จากซอร์สโค้ด |
| Linux (x64) | `Briefing-x.y.z.AppImage` / `.deb` | AppImage: `chmod +x Briefing-*.AppImage` บน Ubuntu 24.04 ขึ้นไปแนะนำให้ใช้ `.deb` (`sudo apt install ./briefing_*.deb`) ซึ่งจะตั้งค่า sandbox ของ Chromium ให้ |

เมื่อเปิดครั้งแรก Briefing จะสร้าง vault ตัวอย่างไว้ใน `เอกสาร/Briefing` ใช้ **Arquivo → Abrir outro vault…** เพื่อเปิดโฟลเดอร์ใดก็ได้

### Build จากซอร์สโค้ด

ต้องใช้ [Node.js 22+](https://nodejs.org)

```bash
git clone https://github.com/renankelm10/briefingMCP.git
cd briefingMCP
npm install
npm start            # รันแอป
npm run dist         # สร้างตัวติดตั้งสำหรับระบบของคุณ (ใน release/)
```

## โฟลเดอร์ทีมใน 3 ขั้นตอน

1. เปิดโฟลเดอร์ที่ต้องการแชร์เป็น vault แล้วกด <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> (**Equipes**)
2. **Criar equipe** → โค้ดเชิญจะถูกคัดลอก ส่งให้เพื่อนร่วมทีมผ่านช่องทางส่วนตัว
3. เพื่อนร่วมทีมเปิด **Equipes → Entrar numa equipe** วางโค้ด และเลือกโฟลเดอร์ว่าง ไฟล์จะมาถึงทันทีที่คอมพิวเตอร์ทั้งสองเครื่องออนไลน์

ต้องเปิด Briefing ไว้บนคอมพิวเตอร์ทั้งสองเครื่องจึงจะซิงก์ได้ ผู้ที่มีโค้ดจะเป็นสมาชิกเต็มรูปแบบ — จงเก็บรักษาเหมือนรหัสผ่าน

## เชื่อมต่อ Claude (MCP)

เปิด **✦ Segundo cérebro → Conectar automaticamente** หรือรัน:

```bash
claude mcp add briefing --scope user -- node "/path/to/briefingMCP/src/mcp/server.mjs"
```

รีสตาร์ต Claude Code เซิร์ฟเวอร์จะเปิดให้เข้าถึง vault ที่เปิดอยู่และโฟลเดอร์ทีมทั้งหมด:

| เครื่องมือ | หน้าที่ |
|---|---|
| `search` | ค้นหาแบบไฮบริดทั้งเชิงความหมายและคีย์เวิร์ด คืนข้อความที่เกี่ยวข้องที่สุดพร้อมไฟล์และบรรทัด |
| `read_note` | เนื้อหาทั้งหมดของโน้ต (ระบุด้วยพาธหรือแค่ชื่อ) |
| `list_notes` | รายการโน้ตใน vault หรือโฟลเดอร์ พร้อมเวลาที่แก้ไข |
| `recent_changes` | โน้ตที่เพิ่งแก้ไข — รวมถึงการเปลี่ยนแปลงที่มาจากเพื่อนร่วมทีม |
| `write_note` | สร้าง เขียนทับ หรือเพิ่มข้อความต่อท้ายโน้ต (ซิงก์ไปยังทีมทันที) |
| `vault_info` | รายการ vault จำนวนโน้ต/ข้อความที่ทำดัชนีแล้ว และสถานะการค้นหาเชิงความหมาย |

ไคลเอนต์ MCP ใดก็ตามที่รองรับเซิร์ฟเวอร์ stdio ใช้งานได้แบบเดียวกัน ใช้ `BRIEFING_VAULTS="/a;/b"` เพื่อระบุ vault เอง

## ความปลอดภัยและความเป็นส่วนตัว

- ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีการเก็บข้อมูลการใช้งาน โน้ตเป็นไฟล์ธรรมดาบนดิสก์ของคุณ
- การเชื่อมต่อเพื่อซิงก์เข้ารหัสต้นทางถึงปลายทางและยืนยันตัวตนด้วยโค้ดเชิญ ไฟล์จากเครือข่ายจะไม่ถูกเขียนออกนอกโฟลเดอร์ที่แชร์ และ Briefing จะไม่เปิดไฟล์ปฏิบัติการที่ได้รับจากผู้อื่น
- embedding คำนวณบนเครื่อง โมเดล (`multilingual-e5-small` ประมาณ 120 MB) ดาวน์โหลดจาก Hugging Face เพียงครั้งเดียว
- คำตอบจาก MCP จะระบุว่าเนื้อหาโน้ตเป็นข้อมูลที่ไม่น่าเชื่อถือ เพื่อลดความเสี่ยงจาก prompt injection

อ่านแบบจำลองภัยคุกคามฉบับเต็มได้ใน **[SECURITY.md](../../SECURITY.md)** โปรดแจ้งช่องโหว่แบบส่วนตัว

## คำถามที่พบบ่อย

**นี่คือ Obsidian หรือไม่?** ไม่ใช่ Briefing เป็นโปรเจกต์โอเพนซอร์สอิสระที่เขียนขึ้นใหม่ทั้งหมด รองรับโฟลเดอร์ Markdown ธรรมดา คุณจึงเปิด vault ที่มีอยู่ได้ แต่ไม่มีส่วนเกี่ยวข้องและไม่ได้รับการรับรองจาก Obsidian

**ต้องใช้อินเทอร์เน็ตไหม?** ใช้เฉพาะตอนค้นหาเพื่อนร่วมทีม (DHT) และดาวน์โหลดโมเดล AI ครั้งเดียว โน้ต การค้นหา และการเข้าถึงของ Claude ทำงานแบบออฟไลน์ได้

**ถ้าสองคนแก้ไขโน้ตเดียวกันจะเป็นอย่างไร?** ส่วนที่ต่างกันจะถูกรวมโดยอัตโนมัติ หากบรรทัดเดียวกันถูกแก้ ทั้งสองเวอร์ชันจะถูกเก็บไว้: หนึ่งในโน้ต และอีกหนึ่งในสำเนา `(conflito de …)` ที่อยู่ข้าง ๆ

**ข้อมูลของฉันอยู่ที่ไหน?** อยู่ในโฟลเดอร์ vault ของคุณ (ไฟล์ `.md`) ข้อมูลของ Briefing เองอยู่ใน `<vault>/.briefing/` (ดัชนี ประวัติ) และในโฟลเดอร์การตั้งค่าของผู้ใช้ (`%APPDATA%\Briefing`, `~/Library/Application Support/Briefing`, `~/.config/Briefing`)

- ตัวติดตั้งที่ลงนามและผ่านการรับรอง
