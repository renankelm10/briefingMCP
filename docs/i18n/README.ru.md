## Что такое Briefing?

Briefing — настольное приложение для заметок, созданное для команд, которым нужна **одна общая база знаний без облачного сервиса посередине**.

- 📝 **Пишите** в обычных Markdown-файлах, которые лежат в обычной папке на вашем компьютере (вашем «хранилище», vault).
- 🔄 **Делитесь** папкой с командой: на каждом компьютере хранится идентичная копия, а изменения идут **напрямую с компьютера на компьютер** со сквозным шифрованием — за считаные секунды.
- 🧠 **Спрашивайте** что угодно: каждая заметка индексируется ИИ-моделью, работающей **на вашем собственном компьютере**, а **Claude** (или любой MCP-клиент) может искать, читать и записывать заметки через встроенный MCP-сервер.

В итоге вы и коллега можете одновременно работать каждый со своим Claude над одними и теми же знаниями компании и всегда видеть последнюю версию.

> Интерфейс пока на **бразильском португальском**. Переводы приветствуются — см. [Как помочь проекту](../../CONTRIBUTING.md).

## Как это работает

<div align="center"><img src="../images/architecture.svg" alt="Архитектура: два компьютера синхронизируются напрямую, у каждого локальный ИИ-индекс, который Claude читает через MCP" width="860"></div>

1. **Вы создаёте команду** и выбираете папку. Briefing генерирует код приглашения вида `BRF-7Q2M-…`.
2. **Коллега вставляет код.** Компьютеры находят друг друга через публичную DHT [Hyperswarm](https://github.com/holepunchto/hyperswarm) — она используется *только* для обнаружения — и открывают прямое соединение, зашифрованное по протоколу Noise. Каждая сторона доказывает знание кода до того, как будет передан хоть один файл.
3. **Каждое изменение отправляется сразу**, кто бы его ни написал — вы, коллега или Claude. Одновременные правки объединяются построчно (как в Git); если двое изменили одни и те же строки, другая версия сохраняется как *копия конфликта*, одинаковая на всех компьютерах — ничего не теряется.
4. **Каждый компьютер индексирует заметки локально** (многоязычные эмбеддинги + поиск по ключевым словам). Claude обращается к индексу через MCP и за миллисекунды получает самые релевантные фрагменты.

## Установка

Скачайте последнюю версию для своей системы в разделе **[Releases](https://github.com/renankelm10/briefingMCP/releases)**.

| Система | Файл | Примечания |
|---|---|---|
| Windows 10/11 | `Briefing Setup x.y.z.exe` | Пока без цифровой подписи: в предупреждении SmartScreen нажмите **Подробнее → Выполнить в любом случае**. |
| macOS 12+ (Apple Silicon) | `Briefing-x.y.z-arm64.dmg` | Пока без нотаризации: щёлкните по приложению правой кнопкой → **Открыть** или выполните `xattr -dr com.apple.quarantine /Applications/Briefing.app`. Mac на Intel: соберите из исходников. |
| Linux (x64) | `Briefing-x.y.z.AppImage` / `.deb` | AppImage: `chmod +x Briefing-*.AppImage`. На Ubuntu 24.04+ лучше `.deb` (`sudo apt install ./briefing_*.deb`) — он настраивает песочницу Chromium. |

При первом запуске Briefing создаёт пример хранилища в `Документы/Briefing`. Чтобы открыть любую папку, используйте **Arquivo → Abrir outro vault…**.

### Сборка из исходников

Нужен [Node.js 22+](https://nodejs.org).

```bash
git clone https://github.com/renankelm10/briefingMCP.git
cd briefingMCP
npm install
npm start            # запуск приложения
npm run dist         # сборка установщика для вашей системы (в release/)
```

## Папки команды за 3 шага

1. Откройте папку, которой хотите поделиться, как хранилище и нажмите <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> (**Equipes**).
2. **Criar equipe** → код приглашения скопирован. Отправьте его коллеге по закрытому каналу.
3. Коллега открывает **Equipes → Entrar numa equipe**, вставляет код и выбирает пустую папку. Файлы придут, как только оба компьютера будут в сети.

Для синхронизации Briefing должен быть запущен на обоих компьютерах. Любой, у кого есть код, становится полноправным участником — обращайтесь с ним как с паролем.

## Подключение Claude (MCP)

Откройте **✦ Segundo cérebro → Conectar automaticamente** или выполните:

```bash
claude mcp add briefing --scope user -- node "/путь/к/briefingMCP/src/mcp/server.mjs"
```

Перезапустите Claude Code. Сервер открывает доступ к текущему хранилищу и всем папкам команд:

| Инструмент | Что делает |
|---|---|
| `search` | Гибридный семантический + ключевой поиск; возвращает самые релевантные фрагменты с файлом и строкой |
| `read_note` | Полный текст заметки (по пути или просто по названию) |
| `list_notes` | Заметки хранилища или папки с датой изменения |
| `recent_changes` | Недавно изменённые заметки — включая изменения, пришедшие от коллег |
| `write_note` | Создать, перезаписать или дополнить заметку (сразу синхронизируется с командой) |
| `vault_info` | Хранилища, число проиндексированных заметок/фрагментов, состояние семантического поиска |

Любой MCP-клиент, поддерживающий stdio-серверы, работает так же. Используйте `BRIEFING_VAULTS="/a;/b"`, чтобы явно выбрать хранилища.

## Безопасность и приватность

- Ни аккаунта, ни сервера, ни телеметрии. Заметки — обычные файлы на вашем диске.
- Соединения синхронизации зашифрованы сквозным шифрованием и аутентифицируются кодом приглашения; файлы из сети никогда не записываются за пределы общей папки, а исполняемые файлы, полученные от других, Briefing никогда не открывает.
- Эмбеддинги вычисляются локально; модель (`multilingual-e5-small`, ~120 МБ) загружается с Hugging Face один раз.
- Ответы MCP помечают содержимое заметок как недоверенные данные, чтобы снизить риск prompt injection.

Полная модель угроз — в **[SECURITY.md](../../SECURITY.md)**. Сообщайте об уязвимостях конфиденциально.

## Частые вопросы

**Это Obsidian?** Нет. Briefing — независимый проект с открытым кодом, написанный с нуля. Он совместим с обычными папками Markdown, поэтому можно открыть существующее хранилище, но проект не связан с Obsidian и не одобрен им.

**Нужен ли интернет?** Только чтобы найти коллег (DHT) и один раз скачать ИИ-модель. Заметки, поиск и доступ Claude работают офлайн.

**Что если двое правят одну заметку?** Разные части объединяются автоматически. Если изменены одни и те же строки, сохраняются обе версии: одна — в заметке, другая — в копии `(conflito de …)` рядом.

**Где мои данные?** В папке хранилища (файлы `.md`). Собственные данные Briefing лежат в `<vault>/.briefing/` (индекс, история) и в папке настроек пользователя (`%APPDATA%\Briefing`, `~/Library/Application Support/Briefing`, `~/.config/Briefing`).
