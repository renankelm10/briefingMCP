## ما هو Briefing؟

Briefing تطبيق ملاحظات لسطح المكتب مصمَّم للفرق التي تريد **قاعدة معرفة مشتركة واحدة دون خدمة سحابية في المنتصف**.

- 📝 **اكتب** في ملفات Markdown عادية موجودة في مجلد عادي على حاسوبك (مستودعك أو الـ "vault").
- 🔄 **شارك** مجلدًا مع فريقك: يحتفظ كل حاسوب بنسخة مطابقة، وتنتقل التغييرات **مباشرةً بين الحواسيب** مشفّرة من طرف إلى طرف خلال ثوانٍ.
- 🧠 **اسأل** عن أي شيء: تُفهرَس كل ملاحظة بنموذج ذكاء اصطناعي يعمل **على جهازك أنت**، ويستطيع **Claude** (أو أي عميل MCP) البحث في ملاحظاتك وقراءتها والكتابة فيها عبر خادم MCP المدمج.

النتيجة: يمكنك أنت وزميلك العمل في الوقت نفسه، كلٌّ مع Claude الخاص به، على معرفة الشركة نفسها، ورؤية أحدث نسخة دائمًا.

> الواجهة حاليًا باللغة **البرتغالية البرازيلية**. الترجمات مرحَّب بها — راجع [المساهمة](../../CONTRIBUTING.md).

## كيف يعمل

<div align="center"><img src="../images/architecture.svg" alt="البنية: حاسوبان يتزامنان مباشرةً، ولكل منهما فهرس ذكاء اصطناعي محلي يقرؤه Claude عبر MCP" width="860"></div>

1. **تنشئ فريقًا** وتختار مجلدًا. يولّد Briefing رمز دعوة مثل `BRF-7Q2M-…`.
2. **يلصق زميلك الرمز.** تعثر الحواسيب على بعضها عبر شبكة DHT العامة الخاصة بـ [Hyperswarm](https://github.com/holepunchto/hyperswarm) — وتُستخدم *فقط* للاكتشاف — ثم تفتح اتصالًا مباشرًا مشفّرًا ببروتوكول Noise. يثبت كل طرف أنه يعرف الرمز قبل تبادل أي ملف.
3. **يُرسَل كل تغيير فورًا**، سواء كتبته أنت أو زميلك أو أحد نماذج Claude. تُدمَج التعديلات المتزامنة سطرًا بسطر (كما في Git)؛ وإذا غيّر شخصان الأسطر نفسها تُحفظ النسخة الأخرى بوصفها *نسخة تعارض* مطابقة على كل الحواسيب — لا يضيع شيء.
4. **يفهرس كل حاسوب الملاحظات محليًا** (تضمينات متعددة اللغات + بحث بالكلمات المفتاحية). يستعلم Claude الفهرس عبر MCP ويحصل على المقاطع الأكثر صلة خلال أجزاء من الثانية.

<summary><b>القائمة الكاملة للمزايا</b></summary>

- تبويبات (تُستعاد عند إعادة التشغيل)، ومبدّل سريع، ولوحة أوامر، وبحث في النص الكامل وبالوسم `#tag`
- معاينة حية: تختفي صياغة Markdown خارج السطر الذي تحرره؛ وتظهر الجداول ومربعات التنبيه والصور ومربعات الاختيار منسّقة مباشرةً
- معاينة عند تمرير المؤشر على الروابط، وإشارات غير مرتبطة يمكن ربطها بنقرة واحدة
- إعادة تسمية ملاحظة أو نقلها تحدّث كل الروابط المؤدية إليها
- قوالب بمتغيرات (`{{title}}`، `{{date:DD/MM/YYYY}}`، `{{time}}`) وقالب جاهز لـ**موجز المشروع**
- سجل إصدارات لكل ملاحظة مع الاستعادة؛ والمحذوفات تذهب إلى سلة محذوفات النظام
- تصدير الملاحظة إلى PDF
- سمة فاتحة / داكنة / حسب النظام، ولون مميز، وحجم الخط، وعرض السطر، ولوحات قابلة لتغيير الحجم، ووضع التركيز
- يعمل مع مجلدات Markdown الموجودة (بما في ذلك مستودعات Obsidian)

## التثبيت

نزّل أحدث إصدار لنظامك من صفحة **[Releases](https://github.com/renankelm10/briefingMCP/releases)**.

| النظام | الملف | ملاحظات |
|---|---|---|
| Windows 10/11 | `Briefing Setup x.y.z.exe` | غير موقَّع رقميًا بعد: في تحذير SmartScreen انقر **مزيد من المعلومات ← التشغيل على أي حال**. |
| macOS 12+ (Apple Silicon) | `Briefing-x.y.z-arm64.dmg` | غير موثَّق من Apple بعد: انقر بزر الفأرة الأيمن على التطبيق ← **فتح**، أو نفّذ `xattr -dr com.apple.quarantine /Applications/Briefing.app`. أجهزة Mac بمعالج Intel: ابنِ من الشيفرة المصدرية. |
| Linux (x64) | `Briefing-x.y.z.AppImage` / `.deb` | AppImage: `chmod +x Briefing-*.AppImage`. على Ubuntu 24.04 وما بعده يُفضَّل ملف `.deb` (`sudo apt install ./briefing_*.deb`) لأنه يضبط بيئة Chromium المعزولة. |

عند التشغيل الأول ينشئ Briefing مستودعًا تجريبيًا في `Documents/Briefing`. استخدم **Arquivo → Abrir outro vault…** لفتح أي مجلد.

### البناء من الشيفرة المصدرية

يتطلب [Node.js 22+](https://nodejs.org).

<div dir="ltr">

```bash
git clone https://github.com/renankelm10/briefingMCP.git
cd briefingMCP
npm install
npm start            # تشغيل التطبيق
npm run dist         # بناء مثبّت لنظامك (في release/)
```

## مجلدات الفريق في 3 خطوات

1. افتح المجلد الذي تريد مشاركته كمستودع، ثم اضغط <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> (**Equipes**).
2. **Criar equipe** ← يُنسخ رمز الدعوة. أرسله إلى زميلك عبر قناة خاصة.
3. يفتح زميلك **Equipes → Entrar numa equipe** ويلصق الرمز ويختار مجلدًا فارغًا. تصل الملفات بمجرد اتصال الحاسوبين.

يجب أن يكون Briefing مفتوحًا على الحاسوبين لتتم المزامنة. كل من يملك الرمز يصبح عضوًا كامل الصلاحيات — تعامل معه ككلمة مرور.

## ربط Claude ‏(MCP)

افتح **✦ Segundo cérebro → Conectar automaticamente**، أو نفّذ:

<div dir="ltr">

```bash
claude mcp add briefing --scope user -- node "/path/to/briefingMCP/src/mcp/server.mjs"
```

</div>

أعد تشغيل Claude Code. يتيح الخادم المستودع المفتوح وكل مجلدات الفرق:

| الأداة | ما تفعله |
|---|---|
| `search` | بحث هجين دلالي وبالكلمات المفتاحية؛ يعيد أكثر المقاطع صلة مع الملف والسطر |
| `read_note` | المحتوى الكامل لملاحظة (بالمسار أو بالاسم فقط) |
| `list_notes` | ملاحظات مستودع أو مجلد مع وقت التعديل |
| `recent_changes` | الملاحظات المعدّلة مؤخرًا — بما فيها التغييرات القادمة من الزملاء |
| `write_note` | إنشاء ملاحظة أو استبدالها أو الإضافة إليها (تُزامَن مع الفريق فورًا) |
| `vault_info` | المستودعات، وعدد الملاحظات والمقاطع المفهرسة، وحالة البحث الدلالي |

أي عميل MCP يدعم خوادم stdio يعمل بالطريقة نفسها. استخدم `BRIEFING_VAULTS="/a;/b"` لاختيار المستودعات صراحةً.

## الأمان والخصوصية

- لا حساب ولا خادم ولا قياس عن بُعد. الملاحظات ملفات عادية على قرصك.
- اتصالات المزامنة مشفّرة من طرف إلى طرف ومصادَق عليها برمز الدعوة؛ ولا يمكن أبدًا كتابة الملفات القادمة من الشبكة خارج المجلد المشترك، ولا يفتح Briefing أبدًا الملفات التنفيذية القادمة من الآخرين.
- تُحسَب التضمينات محليًا؛ ويُنزَّل النموذج (`multilingual-e5-small`، نحو 120 ميغابايت) مرة واحدة من Hugging Face.
- تُعلِّم ردود MCP محتوى الملاحظات بوصفه بيانات غير موثوقة لتقليل خطر حقن التعليمات (prompt injection).

اقرأ نموذج التهديدات كاملًا في **[SECURITY.md](../../SECURITY.md)**. أبلغ عن الثغرات بشكل خاص.

## الأسئلة الشائعة

**هل هذا Obsidian؟** لا. Briefing مشروع مستقل مفتوح المصدر مكتوب من الصفر. وهو متوافق مع مجلدات Markdown العادية، لذا يمكنك فتح مستودع موجود، لكنه غير تابع لـ Obsidian ولا يحظى بتأييده.

**هل يحتاج إلى الإنترنت؟** فقط للعثور على الزملاء (شبكة DHT) ولتنزيل نموذج الذكاء الاصطناعي مرة واحدة. الملاحظات والبحث ووصول Claude تعمل دون اتصال.

**ماذا يحدث إذا عدّل شخصان الملاحظة نفسها؟** تُدمَج الأجزاء المختلفة تلقائيًا. وإذا تغيّرت الأسطر نفسها تُحفظ النسختان: واحدة في الملاحظة والأخرى في نسخة `(conflito de …)` بجانبها.

**أين بياناتي؟** في مجلد مستودعك (ملفات `.md`). أما بيانات Briefing نفسه فتوجد في `<vault>/.briefing/` (الفهرس والسجل) وفي مجلد إعدادات المستخدم (`%APPDATA%\Briefing`، `~/Library/Application Support/Briefing`، `~/.config/Briefing`).
